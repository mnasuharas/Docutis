# Docutis

**An open-source dermatology reference and education toolkit.**

Docutis is an open-source project designed to make structured, evidence-based dermatology information easier to access for physicians, medical trainees, and other healthcare professionals.

The project aims to bring essential clinical information together in a clear and practical format, with a particular focus on everyday dermatology.

## 🎯 Project Goals

Docutis aims to provide quick access to structured information on:

- Dermatologic diseases
- Clinical features
- Dermoscopic findings
- Differential diagnoses
- ICD-10 codes
- Treatment options
- Follow-up recommendations
- Evidence-based guidelines and references

## 🚧 Current Status

Docutis is currently in early development.

The first prototype will focus on a small selection of common and clinically relevant dermatologic conditions. Features and content will be expanded progressively.

## ⚕️ Medical Disclaimer

Docutis is intended for educational and informational purposes only.

It does not replace professional medical judgment, diagnosis, treatment decisions, or consultation of current clinical guidelines. Medical information should be independently verified before being used in clinical decision-making.
